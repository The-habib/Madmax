## 🛠️ Getting Help

1. **GitHub Discussions / Issues:**
   - Search existing [GitHub Issues](https://github.com/The-habib/Madmax/issues) before opening a new one.
   - For bugs, use the [Bug Report Template](.github/ISSUE_TEMPLATE/01-bug-report.yml).
   - For feature proposals, use the [Feature Request Template](.github/ISSUE_TEMPLATE/02-feature-request.yml).
2. **Upstream Documentation:**
   - Standard command-line packages (`pkg`, `apt`), Linux environment configurations, and shell scripts mirror upstream Termux documentation.
